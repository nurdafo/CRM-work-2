# Нурайнур CRM

CRM для лид-форм Meta без лендинга. Заявка из Instagram/Facebook попадает в Cloudflare D1, CRM, Telegram и Google Sheets.

- CRM: <https://nurainur-crm.jumanur62.workers.dev>
- Google Sheets: <https://docs.google.com/spreadsheets/d/1EIaTnBDEoS-z5nIlIqgahkMfSbYelZVqK2xKi6u8aEY/edit>

## Работа с карточками

В CRM карточки перетаскиваются между восемью этапами мышью. В Google Sheets нужно переносить всю ячейку карточки на листе «Канбан» в нужную колонку. Cloudflare считывает изменения каждую минуту, обновляет D1, лист «Заявки», Telegram и затем перестраивает Канбан со свежими счётчиками.

В заметке ячейки хранятся ID и версия карточки. Это защищает от дубликатов и от перезаписи более нового изменения устаревшей карточкой. Если карточка случайно скопирована в две колонки или удалена, этап в CRM не меняется, а очередная перестройка восстанавливает каноническое состояние.

Телефон клиента кликабелен в CRM и обоих листах Google Sheets и открывает `wa.me`. Поддерживаются номера `+7`, `8` и десятизначный формат. Для тестовых лидов Meta выводится сообщение «Тестовый номер — WhatsApp недоступен».

## Качественные клиенты и Meta

Кнопка `★ Качественный` добавляет клиента в Custom Audience `NurAinur CRM - Quality Leads`. Перед отправкой Worker нормализует и хеширует SHA-256 телефон, email, имя и доступный город/регион. Повторное нажатие снимает отметку и удаляет клиента из исходной аудитории.

Карточка показывает состояния `Отправляется`, `Передан в Meta` и `Ошибка — повторить`. Тестовые лиды Meta помечены отдельно и в рекламную аудиторию не отправляются.

После накопления 100 успешно переданных качественных клиентов Worker пытается создать одну аудиторию `NurAinur CRM — Похожие 1% — Казахстан`. До достижения порога CRM показывает количество накопленных клиентов. Существующие рекламные кампании и бюджеты Worker не меняет.

## Разработка и проверка

```sh
npm install
npm run db:local
npm test
npm run check
```

Рабочие проверки:

```sh
npm run kanban:rebuild
npm run kanban:verify
node scripts/test-live-kanban.mjs
```

Секреты хранятся в Cloudflare Workers Secrets и локально в исключённом из Git файле `.dev.vars`. Миграция состояния интеграции Meta находится в `migrations/0002_meta_sync.sql`.
